## 🧑‍💻 About Me

I'm a computer science graduate working full-time on application security at TCS. Day to day, I run **Dynamic Application Security Testing (DAST)** with **Veracode** against web apps and REST APIs. That includes configuring MFA, SSO and custom login workflows so automated scans can authenticate, and helping teams understand and remediate what the scans find.

Outside work, I go deeper on offensive security through TryHackMe CTFs and build tools of my own, from a security scanner to a bare-metal OS in Rust.

**Focus areas**
- 🛡️ Web application and API security testing (DAST, OWASP Top 10)
- 🤖 Python automation and security tooling
- ⚙️ Systems programming and how software works below the syscall layer
- ☁️ Growing interest in cloud security and security automation
