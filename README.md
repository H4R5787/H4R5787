## 🚀 Featured Projects

### 1. [VirusGuard — Virus Detection Web Application](https://github.com/H4R5787/VirusGuard)

A web application that combines file scanning with AI-assisted threat explanations to make security scan results easier to understand.

- Integrates the VirusTotal API to scan files for potential threats.
- Uses Llama 3 to explain scan results in plain language.
- Stores scan history in MySQL for later review.
- Provides an end-to-end workflow for scanning, analyzing, and recording results.

**Tech stack:** Python, Flask, MySQL, Bootstrap, VirusTotal API, Llama 3.

### 2. [HarshOS — Bare-Metal x86_64 Operating System](https://github.com/H4R5787/HarshOS)

An ongoing systems programming project exploring how an operating system works beneath the application layer.

- Implements a freestanding kernel in Rust.
- Includes a VGA text-mode driver and interrupt descriptor table (IDT).
- Explores physical memory allocation and heap allocation.
- Implements PS/2 keyboard input, a virtual filesystem, and an interactive shell.

**Tech stack:** Rust, x86_64, low-level systems programming, memory management.

### 3. [StudyMate — AI Study Assistant](https://github.com/H4R5787/StudyMate)

An offline-first study assistant designed to help students revise their own learning material.

- Uses an on-device TensorFlow Lite model.
- Supports question answering and practice-test generation.
- Tracks learning progress over time.
- Reduces dependence on server-side inference for its core AI workflow.

**Tech stack:** Python, Flask, TensorFlow Lite, machine learning.

### 4. Nova — Custom Programming Language

An ongoing language-design project that combines a Python-based interpreter with a browser-based React REPL.

- Implements an interpreter for a custom-designed language.
- Provides an in-browser environment to experiment with code.
- Explores variable scope, reassignment, and interpreter behaviour.
- Includes work on correcting variable-scoping behaviour inside loops.

**Tech stack:** Python, React, interpreter design, programming language concepts.

*Source code available on request.*

### 5. [AI Social Media Publishing Pipeline](https://github.com/H4R5787/AI-Social-Media-Publishing-Pipeline)

An automation pipeline designed to streamline publishing video content across multiple platforms.

- Processes a single video upload into platform-specific publishing metadata.
- Uses AI to generate SEO-oriented titles, descriptions, and hashtags.
- Integrates publishing workflows for YouTube, Instagram, and Facebook.
- Includes logging, retry handling, and completion notifications.

**Tech stack:** Python, Gemini API, YouTube API, Meta APIs, automation.

### 6. [Python OS Simulator](https://github.com/H4R5787/Python-OS-Simulator)

A lightweight operating system simulator for experimenting with fundamental OS concepts.

- Simulates process management.
- Implements a virtual filesystem.
- Demonstrates round-robin CPU scheduling.
- Provides a practical environment for exploring scheduling logic.

**Tech stack:** Python, operating system concepts, process scheduling, simulation.
